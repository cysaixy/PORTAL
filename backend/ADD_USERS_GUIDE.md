# Adding Teachers and Students Guide

There are 3 ways to add teachers and students to the LOA Portal:

## Method 1: Interactive CLI (Recommended for one-at-a-time)

Run the interactive command-line tool:

```bash
cd backend
npm run add-user
```

This will prompt you for each field:
- **For Teachers**: email, first name, last name, department
- **For Students**: email, LRN, first name, last name, birthdate, sex, guardian info, address

Example session:
```

═══════════════════════════════════════════
```

## Method 2: Quick Batch Add (Recommended for multiple users)

Edit the `backend/quick-add-users.ts` file and add your users to the arrays:

```typescript
const TEACHERS = [
  {
    email: 'teacher1@loa.edu.ph',
    firstName: 'Anna',
    lastName: 'Rodriguez',
    department: 'Mathematics',
  },
  // Add more teachers...
];

const STUDENTS = [
  {
    email: 'student101@loa.edu.ph',
    lrn: '120240000101',
    firstName: 'John',
    lastName: 'Dela Cruz',
    birthdate: '2009-05-15',
    sex: 'M' as const,
    guardianName: 'Maria Dela Cruz',
    guardianContact: '+639171234567',
    guardianEmail: 'maria.delacruz@example.com',
    address: '123 Main St, Alcala, Pangasinan',
  },
  // Add more students...
];
```

Then run:
```bash
cd backend
npm run quick-add
```

The script will:
- Skip users that already exist (based on email)
- Show progress for each user
- Display a summary at the end

## Method 3: Complete Database Reseed

If you want to reset everything and start fresh with sample data:

```bash
cd backend
npm run prisma:migrate
npm run prisma:seed
```

This will:
- Clear all existing data
- Create 30 students
- Create 4 teachers  
- Create sections, subjects, and sample grades
- Set up school year 2024-2025

**⚠️ Warning**: This deletes ALL existing data!

## Important Notes

### LRN Format
- Must be exactly 12 digits
- Example: `120240000101`

### Email Format
- Recommended: `@loa.edu.ph` for teachers
- Students can use any format

### Sex Field
- Must be `'M'` or `'F'` (uppercase)

### Birthdate Format
- Use ISO format: `YYYY-MM-DD`
- Example: `2009-05-15`

### Firebase UID
- Auto-generated by the scripts
- Format: `manual-teacher-{timestamp}` or `manual-student-{timestamp}`

---

## Troubleshooting

### "Email already exists" error
- Each email must be unique
- Check if the user already exists in the database

### "LRN already exists" error
- Each LRN must be unique
- Try a different 12-digit number

### Database connection error
- Make sure PostgreSQL is running
- Check `.env` file has correct DATABASE_URL

## View Current Users

Use Prisma Studio to browse all users:

```bash
cd backend
npm run prisma:studio
```

This opens a web interface at `http://localhost:5555` where you can:
- View all users, teachers, students
- Edit existing records
- Delete records
- See relationships between tables
